    Simulation

    Explore the interface with a virtual pedal.

    Documentation for version 1.1.0
    On this page
    • Open simulation
    • What to try
    • Limitations
    • Local data

    Open simulation

    Use the separate simulation package. The window title and Cube Baby SIMULADO port identify it. The normal edition cannot switch to simulation while running.

    What to try

    You can edit, save and reload A/B/C and perform IR operations in virtual memory. Disconnecting and reconnecting preserves memory within the same process; closing the app resets the virtual pedal. Recovery snapshots are also temporary and are not resumed after restart. Export banks you want to keep.

    Limitations

    Simulation does not generate DSP audio or validate physical USB, real erasure or retention without power. IR slots start empty. Device amp preview/writing and effect-creator previews are unavailable. Local amp import/export remain available. Backing Tracks uses real Windows audio.

    Local data

    The editor uses %LOCALAPPDATA%\CubeControl-Simulation. Theme, language and zoom are shared in %LOCALAPPDATA%\CubeControl.
