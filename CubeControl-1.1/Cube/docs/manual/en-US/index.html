    Three destinations for an edit

    Hearing a change, saving a file and writing to the pedal are different actions.

    Terms along the way

    A short reference to help you follow the instructions.

    Preset
    A set of tone settings. A/B/C identifies three editing and saving destinations.
    IR — impulse response
    A file describing a response used by the cabinet section. An IR WAV is not a song.
    RAM
    Memory used while the device operates. A RAM preview does not automatically replace a saved slot.
    Flash
    Persistent device memory. Writing a slot replaces its content.
    USB-MIDI
    The message channel between editor and pedal. Audio playback uses Windows audio devices.
    dBFS
    A digital audio level scale. 0 dBFS is the reference ceiling; gain in dB is a different control.
