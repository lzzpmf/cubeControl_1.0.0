    Presets, saving and files

    A/B/C, live editing, JSON banks and undo.

    Documentation for version 1.1.0
    On this page
    • Quick workflow
    • Edit and listen
    • Keep and recover your work

    Quick workflow

    Before you start. Connect the pedal and load its bank. Export a copy before important changes.

    1. Select the target A/B/C and the matching physical preset.
    2. Adjust the controls and check the sound.
    3. Use Save A/B/C when you want to write the complete bank.

    When finished. The confirmation reports writing and reading the bank; it does not prove retention after power-off.

    Edit and listen

    A/B/C select the preset being edited. Select the matching preset on the physical pedal to hear it. Available adjustments are sent live; saving is still required for persistence.

    ActionResult
    Save A/B/CWrites the complete three-preset bank and checks it by reading back
    Export bankSaves local editing as a JSON file on the computer
    Import bankAfter confirmation, applies known fields; saving is still required
    Read again or reconnectLoads pedal state; observe replacement and backup messages
    UndoReverts preset edit history; it does not undo IR or amp writes

    Keep and recover your work

    Export the bank before major changes. Reading back does not prove retention after power-off. Use the correct files: bank JSON for A/B/C, WAV for IR, BIN for amp and a dedicated JSON format for each effect creator.

    See Backups and recovery and Pedalboard.
