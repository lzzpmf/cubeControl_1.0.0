# Manuais preservados

Os PDFs e as fontes Markdown estão separados por origem (`oficial` ou `adaptado`) e idioma. O PDF com nome `Oficial` é preservado como documento do fabricante; os arquivos `v2` e as fontes Markdown são adaptações existentes, não novos documentos oficiais. A identificação de idioma acompanha os arquivos existentes e deve ser conferida ao acrescentar versões.

Os guias do cubeControl não são mantidos aqui: sua fonte única é [docs/usuario](../../../../docs/usuario/README.md). O build os publica em `Assets/Documents/guias`. O catálogo também é copiado pelo build.

Não edite os PDFs durante a organização. Preserve autoria e avisos das fontes. Relatórios de investigação não acompanham o pacote.
