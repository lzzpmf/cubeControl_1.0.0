# Presets, gravação e arquivos

## Editar e ouvir
A/B/C selecionam o preset em edição. Escolha o correspondente fisicamente no pedal para ouvir. Ajustes disponíveis são enviados ao vivo; a edição ainda precisa ser salva para persistir.

| Ação | Consequência |
| --- | --- |
| Salvar A/B/C | Grava o banco completo dos três presets e confere por leitura |
| Exportar banco | Guarda a edição local em JSON no computador |
| Importar banco | Após confirmação, aplica os campos conhecidos; salvar continua necessário |
| Reler ou reconectar | Obtém o estado do pedal; observe os avisos de substituição e backup |
| Desfazer | Reverte ajustes do histórico de presets; não desfaz gravações de IR ou amp |

## Guardar e recuperar
Exporte o banco antes de mudanças importantes. Uma leitura de retorno não comprova retenção após desligar. Use os arquivos certos: banco JSON para A/B/C, WAV para IR, BIN para amp e JSON específico para cada criador de efeito.

Consulte [Backups e recuperação](recuperacao.md) e [Pedaleira](pedaleira.md).
